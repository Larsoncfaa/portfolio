MaliAg

Application mobile qui met en relation des vendeurs de produits agricoles et des clients, avec commande et livraison intégrée jusqu'au client final. Mobile application connecting agricultural sellers and customers, with ordering and delivery integrated all the way to the customer.

FlutterDartDjango Django REST FrameworkPostgreSQLJWT
ContexteContext

Un projet académique et personnel autour de l'agricultureAn academic and personal project around agriculture

MaliAg est un projet mobile développé en dehors du cadre scolaire strict, pensé comme une vraie application : les vendeurs de produits agricoles proposent leurs produits, les clients les consultent et passent commande, et la livraison est intégrée au parcours pour acheminer les produits jusqu'au client.

MaliAg is a mobile project built like a real application: agricultural sellers list their products, customers browse and place orders, and delivery is built into the flow to bring products to the customer.

FonctionnalitésFeatures

Ce que l'application permetWhat the app does

  • Publication de produits agricoles par les vendeurs.Sellers can list agricultural products.
  • Consultation du catalogue et passage de commande par les clients.Customers can browse the catalog and place orders.
  • Suivi de la livraison jusqu'au client final.Delivery tracking through to the final customer.
  • Authentification sécurisée des utilisateurs (JWT).Secure user authentication (JWT).
ArchitectureArchitecture

Application mobile + API centraleMobile app + central API

L'application mobile Flutter communique avec une API Django REST Framework, qui centralise les données des vendeurs et des clients dans une base PostgreSQL.

The Flutter mobile app talks to a Django REST Framework API, which centralizes seller and customer data in a PostgreSQL database.
