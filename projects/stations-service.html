ContexteContext

Gérer des stations-service demande des vues très différentes selon la personne : celui qui supervise l'ensemble, celui qui est responsable d'un site, celui qui opère au quotidien. L'application sépare ces trois niveaux dès l'architecture.

Running service stations requires very different views depending on who you are: the person overseeing everything, the person in charge of a site, the person operating day to day. The application separates these three levels from the architecture up.

FonctionnalitésFeatures

  1. Trois niveaux d'accès : admin, responsable, utilisateur.Three access levels: admin, manager, user.
  2. Une seule API sert l'interface web et l'application mobile.A single API serves the web interface and the mobile app.
  3. Base de données PostgreSQL derrière Django REST.PostgreSQL database behind Django REST.
